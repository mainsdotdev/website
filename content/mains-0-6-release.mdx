0.5 let you watch an agent work. With 0.6, you can jump in: edit a file, review the diff, and ship the result without leaving the workspace.

### edit and ship from one place

- **Make the last fix yourself:** Open any file and edit it in Mains. Changes save automatically, and if the file changed elsewhere, you can choose how to resolve it.
- **Commit and open a PR:** Commit, push, or open a PR from the same panel as your diff. Mains can draft the commit message, PR title, and description from the changes.

The editor keeps the workspace diff up to date as you save. When you generate a commit message or PR draft, Mains reads the current changes without staging anything for you.

### keep track of the whole team

- **See every subagent:** A new panel shows what each agent is working on, which tools it used, and what it found. You can see when one is running or done.
- **Pick up where you stopped:** Stopping a run stops its active subagents too. Continue the session and their state comes back with it.
- **Follow the plan:** A small task indicator shows the current step. Hover to see the full checklist.

### find and review changes faster

- **Find the file you need:** Search the workspace by name or path and open a result directly. Git-ignored files stay out of your way.
- **Read the diff at a glance:** Changed and untracked files have clear status labels. File references in agent output open at the right line.

Open a file from search, a diff, or an agent's reply and it appears in the file tree. You can also send a code selection straight back to the chat when you want the agent to take another look.
