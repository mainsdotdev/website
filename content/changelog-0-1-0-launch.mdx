# Mains 0.1.0 is live!

Today marks a major milestone: **Mains 0.1.0 is officially here**.

This first release introduces Mains as a desktop app for executing autonomous AI coding agents in isolated, Git-backed workspaces.

## What's New in 0.1.0

### Core Features

- **Agent Workspaces** - Run Claude Code or GitHub Copilot in dedicated workspaces linked to your repositories
- **Linked Tasks** - Connect GitHub, GitLab, Linear, Jira, and Asana tasks directly to a workspace
- **Diff Viewer** - Review every file change before committing and opening a pull request

### Developer Workflow

- **Code Reviews** - Request structured reviews with severity-tagged findings and file locations
- **MCP Servers** - Extend agents with Model Context Protocol tools for APIs, databases, and internal systems
- **Runs and Observability** - Inspect tool calls, token usage, costs, and workspace diffs for every run
- **File Explorer** - Select relevant files and combine them with linked tasks for focused agent context

### Privacy First

Mains runs agents inside isolated workspaces with full visibility into the exact actions they take. You stay in control of context, changes, and final commits.

## Getting Started

1. Install Mains for your platform
2. Link a repository and create a workspace
3. Attach a task, run an agent, and review the diff before committing

We cannot wait to see what you build with Mains.
