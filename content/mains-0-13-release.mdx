0.13 makes the places you use every day easier to navigate. Your work stays where you put it, and search can take you to the exact line you need.

### find your way around

Home, Search, Pulse, and Connect now live in a slim rail on the left. Code spaces also show Tasks and Plugins there. This gives your conversations more room, while screens such as Pulse and Tasks can use the full window.

- **Pin what matters:** Keep a workspace at the top of the sidebar until you're done with it.
- **Choose the order:** Drag projects and workspaces where you want them. Mains remembers the arrangement when you come back.

### search inside your files

The file explorer can now search file contents as well as names. Switch to **Text**, type a phrase, and see highlighted matches grouped by file. Use the arrow keys to move through results and Enter to open a match at its line.

You can match case, whole words, or a regular expression. Search respects `.gitignore`, so dependencies and build output stay out of the results.

### make Mains yours

Choose a new Dock icon in **Settings → Appearance → App icon**. There are 40 options, from simple colors to gradients, and the change appears as soon as you pick one.

**Add Project** now brings cloning, creating, and opening an existing folder into one dialog. In Work and Chat, Project settings keeps the name, icon, and shared files together. Add a file there and chats in that project can use it from their next message, without changing the original.

### give Codex clearer context

- **Point to a Mac app:** Type `@` in a Codex chat and choose an installed app alongside files and plugins. Codex then knows which app you mean.
- **Work with richer results:** MCP Apps can expand to fill the window. File citations open in the editor, and generated images appear in the chat and deliverables even without a saved file.

You can also paste files and screenshots straight into the composer as attachments.

### work side by side more safely

When two agents share a worktree, each turn's change card now shows only the files that turn touched. If both agents changed the same file, Mains marks it as shared and disables **Undo** for that turn, so reversing one agent's work cannot remove the other's changes.
