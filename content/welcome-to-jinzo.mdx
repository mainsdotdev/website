# Welcome to Jinzo

We're excited to introduce Jinzo, a revolutionary tool that helps you transform information overload into clear, actionable tasks.

## What is Jinzo?

Jinzo is designed to help you:

- **Chat with your tools** - Seamlessly integrate with your existing workflow
- **Generate tasks from data** - Automatically extract actionable items
- **Private by default** - Your data stays secure with local models

## Getting Started

Getting started with Jinzo is easy:

1. Download the app for your platform (macOS or Windows)
2. Connect your tools
3. Start chatting and let Jinzo help you organize your work

```typescript
// Example: Using Jinzo API
const jinzo = new JinzoClient({
  apiKey: process.env.JINZO_API_KEY,
});

const tasks = await jinzo.extractTasks(data);
```
