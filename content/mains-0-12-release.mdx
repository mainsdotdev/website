Mains no longer needs the desktop app to keep agents running. In 0.12, the same backend and web UI can run on a macOS or Linux machine, with your phone and browser connecting to it. The desktop app can connect over SSH too.

### run Mains as a service

Install the server package with Node.js 22.12 or later, then start it:

```bash
npm install --global https://github.com/mainsdotdev/mains/releases/latest/download/mains-server.tgz
mains serve
```

The server uses the desktop app's data by default, so your workspaces, chats, and run history are already there. Only one backend can use that data at a time: close the desktop app before starting the server, or give the server its own data directory.

Use `mains service install` to keep it running without an open terminal. You can make it reachable on your local network or through Tailscale, then pair a phone or open the web UI from a browser.

### make Mains look like yours

**Settings → Appearance** now offers 31 themes, with light and dark options. Pick one for the whole app or give each provider its own look. You can also adjust the accent, background, contrast, and UI and code fonts. Changes appear as you make them, without a reload.

### sign in and browse with less friction

- **One-use browser login:** A browser now signs in with a short-lived link instead of receiving the server's owner token. On the server, `mains web` creates a link when you need one.
- **Tabs stay with their chat:** Switch conversations and the in-app browser brings back the tabs you had open for each one.
- **Files look like files:** Images open as images in the editor, and the browser now has a right-click menu for links, images, and text.
