0.6 let you edit and ship work alongside an agent. Now the issue that started the work and the pull request it becomes live in Mains too. You can go from triage to merge without leaving the app.

### issues and pull requests, together

- **One place to start:** The new Tasks screen puts issues and pull requests in two tabs, with search, filters, and details beside the list.
- **See what needs attention:** Pull requests show their state, checks, author, and diff size. Filter to reviews requested from you, PRs you've reviewed, or your own work.

Mains fetches pull request details from GitHub when you open them, so you see the current checks and merge status.


### review the whole pull request

- **Read everything together:** See the description, reviewers, comments, checks, and a file-by-file diff in one view.
- **Comment on the exact line:** Start a review thread in the diff, then reply or resolve it from the same spot. Your comments appear on GitHub too.
- **Merge when ready:** Choose merge, squash, or rebase. For a draft PR, mark it ready for review instead.


### connect GitHub more easily

You can now sign in with GitHub using a one-time code approved in your browser. There is no need to create a personal access token yourself, though the token option is still available.
