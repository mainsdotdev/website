Until now, every Mains space was built around a code repository. In 0.9, you can choose what a space is for. The app changes with that choice, and so do the tools the agent can use.

### three modes for different jobs

- **Code** keeps the familiar workspace: repositories, branches, diffs, and a terminal.
- **Work** is for documents, reports, and other files. You still work with an agent, without the Git controls around it.
- **Chat** is for conversations that can read but cannot change your files. That limit is enforced for the agent, not just hidden in the interface.

Choose a mode from the sidebar for each space. Work and Chat are available with Claude and Codex; Copilot and Cursor continue to use Code.

### keep related chats together

Work and Chat use **collections** instead of projects. Give a collection a name, add your chats, and attach files or pasted text as shared sources. New turns in those chats use the collection's current sources, so you can update the context as the work changes.

Scheduled pulses work here too. Work has templates for document digests and report drafts; Chat has read-only briefings and recaps. Neither needs a code workspace.

### read the result in Mains

Open Word, Excel, PowerPoint, and Markdown files inside the app when an agent finishes them. You can check the result beside the conversation, then use **Save a copy…** to put the file where you want it.

### keep Git decisions in your hands

Commits and pull requests now go through the Git actions panel, where you can review the diff before acting. An agent can still use the shell for Git when you explicitly ask it to. New installs start with worktrees off; if you already chose a worktree setting, it stays as it was.
