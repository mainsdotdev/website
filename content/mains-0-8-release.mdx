A run keeps working when you switch workspaces. With 0.8, you can still see what it's doing and get back to it in a click. We also filled in a few missing parts of the Git workflow and made the context meter easier to read.

### runs stay in view

- **Keep an eye on background work:** Runs in other workspaces now appear in a small dock in the sidebar. Each card shows its workspace, how long it has been running, and its latest activity.
- **Jump back or stop a run:** Open a card to return to the session, or stop it there if the work has gone off track. The dock gets out of the way when there is nothing else running.

### more of Git, in one panel

- **Pull incoming changes:** The Git panel now shows how far behind your branch is and lets you pull when it can fast-forward. If it cannot, Mains shows why and leaves your work as it was.
- **Start a branch with your changes:** Create a branch from the one you're on without losing uncommitted work.
- **Choose the PR base:** Pick the branch your pull request targets. A generated description uses that same base, so it matches the diff you're reviewing.

### understand your context window

The context meter now shows what is taking up space: messages, tools, skills, memory files, and the system prompt. Hover to see the full breakdown, including free space and the room kept for compaction. The ring changes color as the window fills, making it easier to see when space is getting tight.

### make the app easier to read

- **Set two text sizes:** Adjust the whole interface and code separately, so the sidebar and your diffs can each be comfortable to read.
- **Recognize your space:** A space's theme color now appears in the composer and your messages too. You can set a different color for each space.
