An agent is halfway through a change when you notice a detail it should know: a component already exists, the scope has changed, or the first approach needs another look. That is a good moment to send a correction.

## Keeping the conversation moving

In a Codex chat, you can keep typing while the agent works. A follow-up waits in the queue until the current turn finishes. If it belongs in the work happening now, use **Steer** to send it into the active turn.

The correction stays part of the conversation, so the reason for the change can be read alongside the work that followed it.

## Giving the queue some shape

Some messages can wait. Others depend on what the agent finds first. Edit a queued message, remove one you no longer need, or rearrange the order before it runs.

The goal is to make a small adjustment feel small: add the missing context, let the agent continue, and review the result when it is ready.
