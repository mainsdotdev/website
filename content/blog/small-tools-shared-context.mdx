A prompt rarely stands on its own. The agent might need a file, a particular tool, or instructions your team uses every time it reviews a change.

## Naming what the turn needs

The composer brings files, plugins, and skills into reach through mentions. Choose the item by name and keep writing the request around it.

That small action helps connect an instruction to the context it depends on. A code review skill can accompany a review request; a file can accompany a question about its behavior.

## Building a repeatable habit

Useful context does not have to make every prompt longer. A small set of named tools and skills can make the starting point familiar while leaving room for the details of the task.
