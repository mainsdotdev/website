Sometimes you know the text you are looking for but have no idea which file contains it. A function name, a label on a button, or an error message can be a better starting point than the folder tree.

## Searching where you work

The file explorer searches contents with ripgrep and groups matching lines by file. Open a result to go straight to the line, then use what you found as context for the next message.

Case matching, whole words, and regular expressions let you narrow a query without leaving the workspace. Git ignore rules keep dependencies and generated output out of the way.

## Following the next clue

A useful result often raises another question. Where is this function called? Which component renders this label? Keep searching from the same panel until the path through the code becomes clear.
