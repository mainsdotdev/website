0.19 keeps the work moving: Codex can ask you questions without stopping, repositories clone in the background, and long chats scroll more smoothly.

### answer Codex while it works

Codex can now ask you questions without stopping its work. When it does, a dialog opens above the composer: pick an answer or write your own, step through several questions with **Back** and **Next**, and submit them together. Your answers reach the turn that's still running, or pick the conversation back up if it has finished.

Not ready to answer? Dismiss the dialog. The questions stay in the chat with an **Answer** button, so you can come back to them later. If you send a new message instead, the old questions are marked as no longer needing an answer.

### clone in the background

Cloning a repository no longer holds up the Add Project window. It closes right away, and the clone shows up in your workspace list while it runs, so you can keep working. Cancel it at any time, retry if it fails, and click **Open** when it's ready. You can run several clones at once.

### smoother scrolling

Messages you've loaded now stay in place as you scroll through a chat, so nothing pops in or shifts under you. When you scroll up while an agent is working, the reply in progress stays put, and **Jump to latest** takes you back to it. Long tool outputs still load only when you open them, so long chats stay light.

### smaller changes

- **Outputs you can count on:** Agents now mark the files they're handing to you, so a turn's outputs show finished files rather than drafts and previews made along the way.
- **Big files handled gracefully:** Outputs up to 100 MB stay available. Files too large to preview still show their card, with **Save a copy** and an option to open them in another app.
- **Atlas in pages:** The Atlas library loads 50 items at a time, with **Previous** and **Next** to move between pages, so big libraries stay quick to browse.

We're preparing a beta of Mains for Windows. We'll share more when it's ready.
